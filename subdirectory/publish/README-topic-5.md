## Suggested structure

### 1. Hook

- Etymology: uva/grape — pigmented, vascular, continuous coat.

### 2. Uveal tract overview

- **Iris** → **Ciliary body** → **Choroid** anterior to posterior.

### 3. Iris

- Pupil as light valve; sphincter/dilator (brief); clinical: uveitis presentation teaser.

### 4. Ciliary body

- **Accommodation** + **aqueous production** (non-technical description).
- **Pars plicata vs pars plana:** plicata = processes (zonules, muscle, epithelium); plana = flatter — surgical landmark (pars plana vitrectomy entry).

### 5. Choroid

- Richest blood supply per unit weight (high-yield fact).
- Bruch’s membrane / choriocapillaris mention as bridge to retina topic.

### 6. Blood-aqueous barrier

- Non-fenestrated capillaries + tight junctions (iris/ciliary epithelium) — **aqueous clarity** and **fluorescein patterns** (conceptual).

### 7. Close

- “Uveitis is named for this layer — now you know what layer we’re talking about.”

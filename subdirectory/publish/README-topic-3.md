## Suggested structure

### 1. Hook

- Cornea as main refracting surface (~43 of ~60 D).
- Transparency as an engineering problem, not magic.

### 2. Quick facts grid (scannable)

- Power ~43 D, thickness ~550 μm, horizontal diameter ~11.5 mm, **6 layers**.

### 3. Layer-by-layer (anterior → posterior)

1. **Epithelium** (~50 μm): 5 layers; rapid turnover; **limbal stem cell** dependence.
2. **Bowman’s** (~15 μm): acellular; injury → **permanent scar**, no regeneration.
3. **Stroma** (~500 μm): ~90% thickness; collagen type I; **keratocytes**; transparency via regular lattice.
4. **Dua’s layer** (~15 μm): deep stroma–Descemet interface; strong, acellular; **DALK / “big bubble”** relevance.
5. **Descemet’s** (~10 μm): basement membrane; thickens with age; **Haab’s striae** in congenital glaucoma context.
6. **Endothelium:** single hexagonal layer; **pump**; no meaningful regeneration.

### 4. Stromal transparency — Maurice’s theory

- Uniform fibril diameter (~25 nm) and spacing → destructive interference of scattered light → clarity.
- Oedema disrupts spacing → opacity (connect to endothelial failure).

### 5. Endothelial pump

- Active fluid out of stroma; dehydrated stroma = clear stroma.
- Cell density: normal ~2500–3000/mm²; **critical <500/mm² → bullous keratopathy** (from your diagram).

### 6. Dua’s layer (discovery narrative)

- 2013: new surgical plane; brief, neutral tone — “textbooks evolve.”

### 7. Close

- “Every LASIK scare-story starts with knowing which layer you’re in.”
